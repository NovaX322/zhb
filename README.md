## 🛠️ 安装（客户端导入包）

> 这是一个**客户端导入包**，不是需要手动解压到 `.minecraft` 的普通压缩包。请用启动器的"导入整合包"功能加载。

1. 下载并准备一个支持整合包导入的启动器（如 HMCL / PCL2 等）。
2. 打开启动器，选择 **导入整合包 / 安装整合包**。
3. 选择刚下载的 zip 文件，等待启动器自动解压与安装依赖。
4. 安装完成后，在版本列表中选择对应的整合包版本启动。
5. 首次启动时间较长（需要解压与初始化模组），请耐心等待。

**注意事项：**

- 请确保磁盘剩余空间充足（建议预留 **3 GB 以上**）。
- 若启动器提示内存不足，请在启动器设置里把最大内存调到 **4 GB 以上**。
- 联机请使用本服务器公布的地址，本仓库不提供服务器连接信息。
